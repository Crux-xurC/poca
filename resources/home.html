Poca — a window for localhost development

Poca loads nothing but localhost. Pages, images, fonts and scripts from 127.0.0.1, localhost and [::1] only, and Poca's own pages. Everything else is refused, including downloads.

Poca keeps no history. No browsing history, cache, cookies or page storage survive closing the window.

This covers Poca's window only. Programs started from Poca, or run in a terminal, talk to the network as they themselves do.

Poca（の窓）は localhost 以外を読み込みません。ダウンロードも断ります。

履歴を残しません。閲覧の履歴・キャッシュ・Cookie・ページの保存領域は、窓を閉じれば消えます。

Poca から起動したプログラムやターミナルで動かしたものの通信は、それぞれのプログラムのものです。

Keys

Ctrl+Tab / Ctrl+Shift+Tab next / previous tab · Ctrl+R reload · Ctrl+Shift+B box (bookmarks)
